How to Use This Site

  • Find an SOP: Use the sidebar navigation or the search bar (top right).
  • Download a PDF: Each SOP page has a “View as PDF” link at the top.
  • Suggest a change: Click the “Edit this page” link on any SOP, or open an issue.
  • Create a new SOP: Copy lab_sops/SOP-TEMPLATE.qmd, fill it in, and submit a Pull Request.

SOP Numbering Scheme

SOPs are numbered by topic. Field SOPs use an F prefix and Lab SOPs use an L prefix, but both share the same numeric ranges:
