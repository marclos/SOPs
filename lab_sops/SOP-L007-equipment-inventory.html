1. Purpose

This document is a living inventory of instruments, equipment, and major supplies maintained by the EA Program. It serves as the central reference for locating equipment, tracking ID numbers, and linking each item to its governing SOP. All personnel should consult this inventory before purchasing duplicate items and should update it whenever equipment is acquired, moved, or decommissioned.

2. Scope

  • Applies to: All EA Program equipment in SGM 105, 106, 131, 132, 133, 134, and associated field storage
  • Does not apply to: Consumable supplies (reagents, glassware under $50 replacement cost), personal equipment, or equipment belonging to other departments
  • Maintained by: Lab manager, with updates from all trained personnel

3. How to Use This Inventory

  • Items marked TBD in the ID# column need to be assigned an inventory number during the next audit
  • Items marked TBD in the Location column need to be physically located and recorded
  • The Related SOP column links to the operating procedure for that item; a dash indicates no dedicated SOP exists yet
  • Report discrepancies (missing items, wrong locations) to the lab manager immediately

15. Inventory Audit Procedures

15.1 Annual Audit

At the start of each academic year (or during the summer), a student employee should:

  1. Walk through every room listed in this inventory (SGM 105, 106, 131, 132, 133, 134, 210) and physically verify the presence and condition of each item
  2. Assign an inventory ID number to any item currently marked TBD
  3. Update the Location column if any item has been moved
  4. Note any items that are missing, damaged, or decommissioned
  5. Add any newly acquired equipment
  6. Commit the updated file to the GitHub repository with a descriptive commit message
